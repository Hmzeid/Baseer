# Demo footage plan

Staged or public footage ONLY — no customer data, no Veebase production IP.
Shot on a phone at a friendly site or staged on premises; clips of 10–20s.

1. **Workshop / factory scene** — worker without a helmet near a forklift path.
2. **Construction edge** — missing guard rail + unmarked pedestrian walkway.
3. **Farm scene** — irrigation equipment + worker PPE check.

Each scene: one wide shot + one close walk-through. These feed the demo video
(problem → upload → live Arabic report) recorded on Nov 1.
